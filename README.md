# Project Overview
Creating a website for a business called King Car Wash.
It is an existing local business in my community.
It specializes in detailing cars, making them feel and look brand new.
The website is for the business to get more recognition.
I am going to make use of HTML for structure, CSS for desogn to attract people and JavaScript for functionality.

# PART1
Part 1 focuses on HTML. Create web pages of the website to be able to know what is needed for the website to be successful.
Part1 I get all the information I need to know about the business. I do all the research by gathering: images,social media platforms, contact details, location of the business and why it needs the website.
Create the structure of how you want the website to look like.

# Website Goals and Objectives
•	Generate qualified bookings and enquiries from the local target market.
•	Position King Car Wash as a premium, trustworthy detailing brand online, matching the quality clients receive in person.
•	Present service packages, pricing tiers and the doorstep/on-site convenience offering.
•	Provide an easy, low- friction way for customers to request a booking (online form, WhatsApp chat, email or a phone call).
•	Showcase real results and social proof to build trust with new customers.
•	Support the brand’s community mission by communicating the youth employment story, which strengthens brand loyalty and local goodwill.

# Key Features and Functionality
•	Number of booking form submissions and WhatsApp/phone clicks per month.
•	Website traffic: unique visitors and returning visitors per month.
•	Conversion rate: percentage of visitors who complete a booking enquiry.
•	Average session duration and bounce rate (indicates whether visitors engage with the content).
